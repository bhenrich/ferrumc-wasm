# FerrumC

A high-performance Minecraft Java Edition server implementation written in Rust.

> ⚠️ **This branch (`rework/ferrumc-v2`) is an active rewrite.** For the current working version, see `master`.

## Status

**v2 is in early development.** The architecture is designed, the workspace is scaffolded, and implementation is underway milestone by milestone.

See `docs/architecture/overview.md` for the design and `CLAUDE.md` for development instructions.

## Building

```bash
cargo build --release
```
